# Peter Beauty Salon

موقع عربي متجاوب لصالون Peter Beauty Salon في سوهاج.

## Structure

- `index.html` — الصفحة الرئيسية.
- `css/style.css` — كل تنسيقات الموقع بشكل منفصل.
- `js/app.js` — التاريخ، التحقق من الهاتف، وتحويل بيانات الحجز إلى رسالة WhatsApp.

## Deployment

المشروع جاهز للنشر كـ GitHub Pages أو أي استضافة Static.
