# NOVA AI — واجهة المساعد الذكي

واجهة عربية متجاوبة للمحادثة مع نموذج مفتوح الأوزان مستضاف، والإملاء الصوتي وقراءة الردود، واستوديو توليد الصور، ومساحة تصفح مدمجة، ووضع مساعد البرمجة.

## الملفات
- `index.html` — الواجهة.
- `styles.css` — التصميم المتجاوب.
- `app.js` — المحادثة والتفاعلات وربط API.

## التشغيل
يمكن فتح `index.html` للتجربة البصرية، لكن بعض المتصفحات تمنع ميزات معينة عند فتح الملف مباشرة. الأفضل تشغيل خادم static محلي أو نشر المجلد على GitHub Pages. الواجهة لا تتصل بمزوّد النموذج مباشرة حتى لا ينكشف مفتاح API.

## ربط الخادم
1. انشر مجلد `nova-ai-api` كمشروع Vercel منفصل، مع Root Directory = `nova-ai-api`.
2. أضف متغير البيئة `HF_TOKEN` في إعدادات المشروع على Vercel، بصلاحية استدعاء Inference Providers. لا تضعه في ملفات الواجهة.
3. انشر الخادم، ثم افتح NOVA > الإعدادات والاتصال وأدخل عنوان الخادم HTTPS.
4. استخدم «حفظ الإعدادات واختبار الاتصال». بعد نجاح health check جرّب سؤالًا فعليًا؛ ففحص الصحة لا يضمن أن كل نموذج متاح أو مجاني.
5. إذا رفض المتصفح الطلب بسبب CORS، حدّث `ALLOWED_ORIGINS` في الخادم بعنوان موقع الواجهة المنشور.

## الميزات وحدودها
- المحادثة تستخدم نموذجًا عبر Hugging Face Inference Providers. التوفر والسرعة والحصص والتكلفة تعتمد على النموذج والمزوّد وحسابك.
- الصوت يعتمد على Web Speech API في المتصفح؛ التوافق والأصوات والأذونات تختلف بين المتصفحات.
- توليد الصور يستدعي endpoint منفصلًا ويحتاج إلى نموذج ومزوّد متاحين.
- مساحة المتصفح تعرض المواقع داخل iframe عند سماح الموقع بذلك؛ لا تمنح تحكمًا كاملًا في متصفح النظام ولا تتجاوز سياسات المواقع.
- لا يوجد توليد فيديو موصول في هذا الإصدار؛ يتطلب مزوّدًا يدعم text-to-video وإعداداته وتكاليفه.
- المساعد لا ينفّذ أوامر نظام ولا يشغّل الكود الناتج. راجع الكود قبل تشغيله.
- لا يوجد تسجيل دخول أو تخزين محادثات سحابي في هذه النسخة. السجل محلي في sessionStorage.

## فحوصات يدوية
- افتح الموقع على الهاتف وسطح المكتب.
- اضبط API base وتأكد من نجاح `/api/health`.
- اختبر محادثة قصيرة ثم طلب برمجي.
- اختبر الإملاء الصوتي بعد منح إذن الميكروفون.
- اختبر توليد صورة منفصلًا بعد التأكد من صلاحيات المزوّد.
- تحقق من CORS في أدوات المطور عند اختلاف نطاق الواجهة والخادم.

## الترخيص
واجهة NOVA AI هذه مقدمة تحت MIT؛ راجع تراخيص النماذج ومزوّدي الاستدلال بشكل منفصل.
