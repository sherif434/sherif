# Dr. Sara Lotfy Dental Clinic — Preview Website

A responsive Arabic RTL website concept for a dental clinic in Sohag, Egypt.

## Preview
When GitHub Pages is enabled for the parent repository, the nested site is intended to be available at:
https://sherif434.github.io/sherif/dr-sara-lotfy/

## Important content status
- Phone and Google Maps link are prefilled from information previously supplied/researched, but should be confirmed with the clinic before public launch.
- Clinic-specific address, hours, doctor portrait, credentials, confirmed service list, and official clinic photos are not yet verified.
- Current gallery imagery is illustrative stock photography and is explicitly labelled as such in the page.
- Appointment form opens a prefilled WhatsApp message; it does not store data or confirm a booking.
- No backend, database, or admin panel is included.
- This is an unsolicited sales preview concept. Obtain clinic approval before representing it as the clinic's official website or publishing clinic-specific content.

## Deploy
This site is placed in the `dr-sara-lotfy/` subfolder to avoid replacing the existing root website. GitHub Pages must be enabled for the parent repository and serve the branch/folder containing this path.

## Customization checklist
1. Confirm clinic phone and WhatsApp number.
2. Confirm address and replace the map link if needed.
3. Confirm opening hours.
4. Confirm the services offered and professional credentials.
5. Replace illustrative stock photos with clinic-owned photos, with permission.
6. Add approved privacy information and contact process.
7. Test the deployed preview on mobile and desktop.
